# 수업 운영 안내

## 수업 전

- 교사 공간에서 학급마다 별도의 반을 만들고 코드를 공유합니다.
- 학생들이 입력할 이름의 형식을 통일합니다. 예: `민서`, 동명이인은 `민서12`.
- 학생은 본인이 질문할 **짝의 이름**을 적는다는 점을 먼저 안내합니다.
- 각 질문은 실제 전반적인 성격이나 취향을 판정하는 검사가 아니라, 제시된 보기 중 한 개를 골라 대화하는 활동입니다.

## 활동 순서

1. A가 B의 이름을 입력합니다. **짝과 인터뷰 시작하기**를 누르면 B의 이름이 먼저 DB에 등록됩니다.
2. A가 화면의 프랑스어 질문을 읽습니다. B는 제시된 대답 틀로 대답합니다.
3. A가 B의 답을 선택합니다. 선택한 프랑스어 표현이 대답의 빈칸에 연결되어 말하기를 돕습니다.
4. 같은 방식으로 다섯 질문을 진행합니다. 이전 질문이나 상단 번호로 돌아가 수정할 수 있습니다.
5. 확인 화면에서 B가 내용을 확인한 뒤 A가 **제출하기**를 누릅니다. 다섯 답을 한 번에 저장합니다.
6. 역할을 바꿉니다. B가 A의 이름으로 새 인터뷰를 진행합니다.
7. **우리 반 대시보드**에서 각 학생은 자신의 이름을 고릅니다. 자신을 제외한 친구들 중 답이 가장 많이 겹치는 친구가 나타납니다.
8. 질문별 그래프를 보며 우리 반에서 어떤 선택이 많았는지 프랑스어로 이야기합니다.

한 기기를 두 학생이 함께 써도 됩니다. 제출 완료 화면에서 **역할 바꿔 인터뷰하기**를 누르면 같은 반에서 새 이름으로 시작할 수 있습니다.

## 답변 수정

- 제출 전: 질문 화면의 선택을 바꾸거나 확인 화면의 **수정** 버튼을 누릅니다. 아직 그래프에는 반영되지 않습니다.
- 제출 후: 응답을 기록했던 같은 브라우저의 홈에서 **이 기기에서 기록한 응답 수정 / 이어 쓰기**를 엽니다. 이름 옆의 수정 버튼을 눌러 바꾸고 다시 제출합니다.
- 수정하면 기존 한 사람의 응답이 갱신됩니다. 인원이 중복으로 늘어나지 않습니다.
- 한 이름을 다른 기기에서 임의로 덮어쓸 수 없습니다. 처음 기록한 기기를 사용할 수 없다면 교사가 해당 응답을 지운 뒤 다시 등록하게 합니다.

## 대시보드 읽기

| 표시 | 의미 |
| --- | --- |
| 최종 제출한 친구 | 다섯 질문을 모두 제출한 응답 수. 이름만 등록한 작성 중 응답은 제외합니다. |
| 일치율 | 동일한 보기를 고른 질문 수 ÷ 5 × 100. 0, 20, 40, 60, 80, 100% 중 하나입니다. |
| 동점 친구 | 가장 높은 일치 개수의 친구가 여러 명이면 모두 표시합니다. 5명 이상일 때는 펼치기 버튼을 누릅니다. |
| 질문별 그래프 | 최종 제출한 사람을 기준으로 각 보기의 인원과 비율을 표시합니다. |
| 자동 조회 | 기본 10초마다 DB에서 새 결과를 가져옵니다. 대시보드가 보일 때 동작하고, 최근 입력/선택 직후에는 다음 주기로 미룹니다. |
| 새로고침 | 원할 때 즉시 DB에서 응답을 다시 읽습니다. 브라우저 전체를 새로고침하지 않아도 됩니다. |

아직 인터뷰를 해 준 짝이 제출하지 않았다면 자신의 이름이 대시보드 선택 목록에 나타나지 않습니다. 본인의 응답이 한 개뿐이면 비교할 친구가 없다는 안내가 나옵니다.

## 교사 관리

- **반 목록:** 반별 코드, 제출 인원, 작성 중 인원, 종료 예정 시각을 확인합니다.
- **참여 링크 복사:** 반 코드가 미리 입력된 학생용 홈 링크를 복사합니다.
- **제출 마감하기:** 신규 이름 등록과 답변 제출/수정을 막습니다. 기간 내라면 학생들의 결과 조회는 가능합니다.
- **응답 다시 열기:** 참여 기간이 남아 있을 때 응답을 다시 받습니다. 참여 기간 자체는 연장하지 않습니다.
- **학생 응답 관리:** 잘못 입력한 이름, 중복 시도, 작성 중인 응답 등을 삭제할 수 있습니다.
- **CSV 다운로드:** 최종 제출한 응답의 이름과 다섯 답을 파일로 내보냅니다. UTF-8 BOM을 포함하므로 Excel에서 한국어를 읽을 수 있습니다.
- **반 삭제:** 반 코드와 해당 반의 모든 이름·답변을 함께 삭제합니다. 취소할 수 없습니다.

참여 기간이 끝나면 학생의 조회와 제출은 모두 종료됩니다. 교사는 계속 조회하거나 CSV로 내보낼 수 있습니다. **기간 종료가 자동 삭제를 의미하지는 않습니다.** 사용을 마친 반은 교사 공간에서 삭제해 정리하세요.
