# Narakeet 음성 파일

질문 음성은 Narakeet의 **French-Metropolitan / Guillaume** 설정으로 생성했습니다.

- `qN-question.mp3`: 해당 문항의 프랑스어 질문
- `qN-answer-M.mp3`: 해당 선택에 대응하는 완성된 프랑스어 대답

보기를 선택하면 해당 대답 음성을 재생합니다. 대답 문장의 스피커 버튼도 같은 음성을 사용합니다.
