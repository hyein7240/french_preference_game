# Narakeet 음성 파일

음성은 Narakeet의 **French-Metropolitan / Guillaume** 설정으로 생성해 주세요. 생성된 MP3를 이 폴더에 파일명 변경 없이 넣으면 질문 화면에서 재생됩니다.

- `qN-question.mp3`: 해당 문항의 프랑스어 질문 문장
- `qN-option-M.mp3`: 해당 선택지의 프랑스어 단어 또는 문장
- `qN-answer-M.mp3`: 선택 후 화면에 표시되는 완성된 프랑스어 대답 문장
