# Binôme — 너와 나, 우리의 취향

일반고등학교 1학년 프랑스어 수업용 짝 인터뷰 웹사이트입니다. 크림색·올리브색·살구색·노란색, 둥근 카드와 프리텐다드 폰트로 구성했습니다. 모바일과 데스크톱 레이아웃을 제공합니다.

## 가장 먼저

1. **화면만 체험:** 압축을 푼 뒤 `DEMO.html`을 브라우저로 여세요. DB 연결 없이 예시 응답 8명으로 활동 흐름을 확인할 수 있습니다. 이 파일의 저장 데이터는 실제 수업 DB와 분리됩니다.
2. **실제 수업 준비:** [한국어 설치·배포 안내](docs/SETUP.md)를 따라 Supabase DB와 교사 계정을 준비하고 `config.js`의 공개 설정 두 값을 입력하세요.
3. **GitHub 배포:** 이 폴더의 **내용물**을 저장소 루트에 올리고 GitHub Pages를 설정하세요. `index.html`이 저장소 루트에 있어야 합니다.
4. **수업 시작:** 사이트의 **교사 공간**에서 반을 만들고, 생성된 반 코드 또는 참여 링크를 학생들에게 공유하세요.

설정 전 `index.html`도 체험 모드로 실행됩니다. **체험 모드는 같은 기기의 브라우저에만 저장됩니다.** 여러 학생의 기기에서 결과를 공유하려면 Supabase 연결이 필요합니다. 실제 DB나 GitHub 계정은 이 패키지에 연결되어 있지 않습니다.

## 포함된 기능

- 짝의 이름을 DB에 먼저 등록하고 다섯 문항을 한 번에 최종 제출
- 프랑스어 질문·대답 예시, 한국어 해석, A–D 보기, 선택한 보기를 연결한 대답 문장
- 이전/다음 질문, 답변 확인, 문항별 수정, 같은 기기에서 제출 후 수정
- 질문에 답한 사람의 이름으로 응답 저장: A가 B를 인터뷰하면 B의 선호로 기록
- 자신의 이름 선택 → 다섯 답변 중 일치 개수가 가장 많은 친구 연결, 동점 모두 표시
- 질문별 인원·비율 그래프, 수동 새로고침, 기본 10초마다 자동 조회
- 반 코드별 데이터 분리, 반 생성·제출 마감·학생 응답 삭제·반 삭제·교사 CSV 내보내기
- 교사 로그인과 교사별 반 소유권 확인, 학생은 계정 없이 반 코드로 참여
- 프리텐다드 Regular/Bold 폰트 원본과 라이선스 포함: 별도의 폰트 CDN 요청 없음

## 개발용 실행

Node.js 20 이상이 있으면 별도 패키지를 설치하지 않고 실행할 수 있습니다.

```bash
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. `index.html`을 직접 더블클릭하면 브라우저의 ES 모듈 제한 때문에 작동하지 않을 수 있으므로 단일 체험 파일 `DEMO.html`이나 위 서버를 이용하세요.

```bash
npm test
npm run build
```

`npm run build`는 배포에 필요한 파일만 `_site/`에 복사합니다. DB 스크립트·문서·테스트·체험 파일은 이 배포 폴더에서 제외됩니다. `npm install`은 필요하지 않습니다.

프랑스어 문항을 바꿀 때는 `js/questions.js`를 수정하세요. 문항 수나 보기 수를 바꾸려면 집계 화면과 DB의 답변 검증 제약도 함께 변경해야 합니다. 변경 후 단일 체험 파일은 `node scripts/make-demo.mjs`로 다시 생성합니다.

## 검증 범위

자동 테스트는 집계·동점 매칭·미완료 제외·제출/수정·반 분리·편집 토큰·중복 이름·오류 처리·API 요청 형식과 화면 이동을 확인합니다. 실제 Supabase 프로젝트 연결 및 GitHub Pages 배포는 사용자의 설정이 필요합니다. 제공 환경에서는 실제 브라우저의 화면 렌더링과 기기 간 DB 동기화를 실행하지 못했으므로, 배포 뒤 `docs/SETUP.md` 마지막의 두 기기 점검을 진행하세요.

프리텐다드는 SIL Open Font License 1.1에 따라 포함했습니다. 출처와 원문 라이선스는 `assets/fonts/OFL.txt`를 참고하세요.
